# AI Personal Assistant

An AI-powered personal assistant built using Gemini AI and Make.com.

## Features

* Memory storage and recall using Google Sheets
* Calendar event creation and retrieval
* PDF knowledge retrieval from Google Drive
* Web search integration
* Intent classification and workflow routing
* Webhook-based communication

## Tech Stack

* Gemini AI
* Make.com
* Google Calendar API
* Google Sheets
* Google Drive
* JSON Parsing
* Webhooks

## Architecture

User Query → Intent Classifier → Router → Specialized Workflow → Response

## Current Capabilities

* Save Memory
* Recall Memory
* Create Calendar Events
* Read Calendar Events
* Query PDF Documents
* Web Search
